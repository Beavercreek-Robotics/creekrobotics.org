## Periodic Update Schedule

The table below identifies every item that is not driven by dynamic data but will need to be updated as the club changes from season to season or year to year.

| Item | File Path | Description | Recommended Update Frequency |
|------|-----------|-------------|-------------------------------|
| Current season year | `src/config/club.js` → `CURRENT_SEASON_YEAR` | Competition year label (e.g. `"2025–26"`) | **Each August** when the new season launches |
| Current game name | `src/config/club.js` → `CURRENT_GAME_NAME` | Name of the active VRC game (e.g. `"Push Back"`) | **Each August** when the new game is announced |
| Current game link | `src/config/club.js` → `CURRENT_GAME_LINK` | URL to the official game manual | **Each August** when the new game manual is released |
| Competition schedule (fallback) | `src/config/club.js` → `COMPETITION_SCHEDULE` | Static fallback list of events, used when the Robot Events API is unavailable | **Each fall** at the start of the competition season |
| Meeting schedule | `src/config/club.js` → `MEETING_SCHEDULE` | Days/times/description shown on the Contact and For Parents pages | **Each season** whenever the meeting cadence changes |
| Board of directors | `src/config/club.js` → `BOARD` | President, VP, Treasurer, and other officer names | **Each year** after officer elections |
| School advisors | `src/config/club.js` → `SCHOOL_ADVISORS` | Faculty advisor name(s) at Beavercreek High School | **When advisors change** |
| Sponsorship tiers | `src/config/club.js` → `SPONSORSHIP_TIERS` | Tier names, minimum dollar amounts, and benefits | **Each season** or when the board revises the sponsorship program |
| Default team statistics | `src/config/club.js` → `DEFAULT_TEAM_STATS` | Fallback stats displayed when the generated stats are unavailable (years active, students served, awards won) | **Annually** — verify after each season |
| Team number prefixes | `src/config/club.js` → `TEAM_NUMBER_PREFIXES` / `TEAM_NUMBERS` | Robot Events team-number prefixes used for live schedule lookups | **When new programs or teams are added** |
| Social media URLs | `src/config/club.js` → `SOCIAL_INSTAGRAM`, `SOCIAL_FACEBOOK`, `SOCIAL_YOUTUBE`, `SOCIAL_TWITTER` | Platform URLs shown in the footer and Contact page | **When accounts are created or changed** |
| Student testimonials | `src/content/students.js` → `testimonials` | Quotes shown on the For Students page | **Annually** — collect new quotes from current/recent students |
| Mentor testimonials | `src/content/engineers.js` → `mentorTestimonials` | Quotes shown on the For Engineers page | **Periodically** — collect new quotes from active mentors |
| Mentor impact statistics | `src/content/engineers.js` → `impactStats` | Stats block on the For Engineers page (mentor-to-student ratio, STEM career rate, etc.) | **Annually** — verify figures with current data |
| Competition schedule (source) | `src/data/competition-schedule.json` | Source list of competition events for the season (date, name, location) | **Each fall** — populate before the season starts |
| Generated competition schedule | `src/generated/competition-schedule.json` | Auto-generated by `npm run generate:events` from the Robot Events API | **Run before each deployment** or let CI generate automatically |
| Generated recent accomplishments | `src/generated/recent-accomplishments.json` | Auto-generated list of awards/achievements from the Robot Events API | **Run before each deployment** or let CI generate automatically |
| Generated team stats | `src/generated/team-stats.js` | Auto-generated statistics from the Robot Events API | **Run before each deployment** or let CI generate automatically |
| Current sponsor logos | `src/components/page-content/SponsorsPageContent.vue` → sponsor grid section | Grid of sponsor logo images shown on the For Sponsors page | **Each season** — add/remove logos as sponsorships change |
| Team photo | `src/assets/images/teams/` | Club photo used in the About section of the home page | **Annually** — replace with current season's team photo |
| Logo images | `public/logo.jpg`, `public/logo-small.jpg`, `public/logo.svg`, `public/logo.webp` | Club logo shown in the header and footer | **If branding changes** |
